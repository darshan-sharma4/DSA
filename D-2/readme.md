# Primitve Data Types in c++
1. int -- used to store integer value it has 4 byte memory space reserved.
2. char -- used to store the character value it has 1 byte space reserved.
3. float -- used to store decimal number value its has 4 byte of space reserved.
4. bool -- used to store bollean value its has 1bytes of space.
5. double -- used to store the decimal value  data but its has more space than float (8byte).

# Type Casting (converting one data format to some other data format)
## conversion 
--> conversion is a implicit process which is done by complier this generally happens when we convert small data type into big data type no need to instruct the complier for doing that

**ex - char to int**

## casting 
--> casting is a explicit process in this we need to instruct our complier to convert the data from one type to another type forcefully.

**ex -- double to float**
int a =5 ;
int b = (float)a;
