# Time & Space complexity
Its defines as the actual time taken by a function in respective of an input.

## BigO Notation
It gives worst case complexiety(upper bond)     

## Space complexity
Amount of space taken by an algoritm as function of input size(n).    
# Common Time Complexity
1. O(1)--Constant.
2. O(n)--Linear time complexity.
3. O(n^2) & O(n^3)--Bubble sort
4. O(logn)
5. O(nlogn)
6. O(2^n)
7. O(n!)
