## Recursion
--> Recursion is a programming technique where a function calls itself directly or indirectly to solve problems by breaking them into a smaller, self-similar problems. It require a base case to terminate.It creates a call stack to store the recursive calls        
 

**Recurance Relation**               
--> It is used to calculate the time complexity;
1. f(n)= print"n"+ f(n-1); 
2. f(n)= total call made + work done in each call;      

NOTE         
In recursion a call stack is created which can take extra space.
