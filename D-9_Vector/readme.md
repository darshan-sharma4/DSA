## Vector
Vector is like an array but dynamic in nature means it's size is not fixed.

In c++ there is STL(standard template library) which is a collection of already define data structure like stack, queues,hashTable.

# static vs Dynaic allocation
Array are static means it creates on compile time on the other hand vector are dynamically allocated, created at runtime.     
Array used stack memory data structure while vector uses heap data structure for storing data.
